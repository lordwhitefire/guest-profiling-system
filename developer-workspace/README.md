# Developer Workspace

This is the Developer agent's home base. Briefs, notes, plans, and reports live here by default.

## Structure

```
developer-workspace/
  README.md        this file
  briefs/          one file per task: what was asked, what done looks like
  notes/           verification notes — current state, change points, dependencies
  plans/           the change plan — smallest step, invariants, order
  reports/         the honest report after the task — built, verified, not verified
  scripts/         workspace generator scripts
```

It outlives this conversation. A change left only in chat will be lost.
